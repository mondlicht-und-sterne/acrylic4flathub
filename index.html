Installation

1. Download
Lad dir Acrylicons-v1.0.zip runter und entpacke es.

2. Ordner verschieben
Verschiebe den Ordner Acrylicons nach:
~/.local/share/icons/

3. Theme aktivieren

KDE Plasma: Systemeinstellungen → Erscheinungsbild → Symbole
GNOME: Gnome Tweaks → Erscheinungsbild → Symbole

QR Code

Scanne für Download

Scan the code on the KEKILA bottle

Every bottle with an Acrylicons label has a QR code.

Scan this QR code, Download the .zip file from the latest release at codeberg.org/mondstern/Acrylicons/releases

Extract the .zip file, run the install.sh script.

Select the ‘Acrylicons’ icon theme from the settings.
Settings / Themen / Symbole / Acrylicons
